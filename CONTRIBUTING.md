# Contributing

Thanks for helping improve Bundle Sorter.

1. Create a focused branch for your change.
2. Keep unrelated formatting changes out of the commit.
3. Run `./gradlew build` before opening a pull request.
4. Describe the Minecraft, Fabric Loader, and Meteor Client versions used for testing.
5. For inventory automation changes, explain how cursor items and interrupted transfers are handled safely.

Please do not commit generated directories, IDE metadata, Minecraft runtime files, or personal configuration.
