# Map Bundle Collector & Map Art Viewer
**Made by tysonsxz**

A Meteor Client addon for Fabric / Minecraft 26.2.

## ⚙️ Requirements
- **Minecraft**: `26.2`
- **Fabric Loader**: `>= 0.19.4`
- **Meteor Client**: for 26.2
- **Java**: 25+

---

## 🚀 How to Install
1. Make sure you have **Fabric Loader** and **Meteor Client** installed for Minecraft 26.2.
2. Press `Win + R`, type `%appdata%\.minecraft\mods` and press **Enter**.
3. Place `map-bundle-collector-1.0.0.jar` into your `mods` folder.
4. Launch Minecraft and enjoy!
