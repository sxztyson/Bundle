# Map Bundle Collector & Map Art Viewer
**Made by tysonsxz**

A Meteor Client addon for Fabric / Minecraft 1.21.11.

## ⚙️ Requirements
- **Minecraft**: `1.21.11`
- **Fabric Loader**: `>= 0.18.2`
- **Meteor Client**: for 1.21.11
- **Java**: 21+

---

## 🚀 How to Install
1. Make sure you have **Fabric Loader** and **Meteor Client** installed for Minecraft 1.21.11.
2. Press `Win + R`, type `%appdata%\.minecraft\mods` and press **Enter**.
3. Place `map-bundle-collector-1.0.0.jar` into your `mods` folder.
4. Launch Minecraft and enjoy!
